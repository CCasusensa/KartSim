# 游戏语言图片

图片中的文字使用完整的本地化素材。程序按当前语言选择 PNG，再交给原来的 BML、Canvas 或图片组件绘制；普通状态、悬停、按下和禁用状态分别保存为资源。

## 素材来源

- 中文沿用原版图片；原本只有韩文的官方指南按钮补有中文图片。
- 英文和韩文优先采用已核验语言与尺寸的原版素材。`@zz` 不是通用的韩文标记，只对已核验的路径启用。
- 缺少原版的素材，以原图为参考通过内置 imagegen 生成整张本地化图片，保持角色、图标、背景和按钮状态。生成后的图集按原资源尺寸离线切片。
- 每个目录的 `spec.json` 或 `manifest.json` 记录源路径、语言、文件和来源。`generation.json`、提示词文件和 `source/` 保存生成及切片依据；生成结果保存在仓库中，重新打包不调用图片服务。
- 用户昵称、房间名、自定义地图名、管理员新上传的图片仍保留原内容。

## 构建与校验

在 `client/` 目录执行：

```sh
npm run build:locale-art
npm run test:locale-art
npm run test:i18n
```

PNG 源文件与 Rho 包使用 Git LFS，首次检出后需获取对应 LFS 文件。切片工具使用 ImageMagick；仅重新封装已有切片无需 ImageMagick。

`tools/build-localized-ui.mjs` 汇集各目录清单，检查重复路径和 PNG 格式、尺寸，输出 `build/localized-ui/locale_ui.rho`，然后更新：

- `mirror/p3553/locale_ui.rho`
- `mirror/__p3553/resources`
- `mirror/__p3553/archive-index`
- `assets/locale-ui/manifest.json`

资源包挂载到 `locale_ui/<语言>/<原资源路径去掉语言后缀>`。源档案保持原状。资源索引中的 SHA 用于下载与缓存校验；语言包归入基础资源。当前包包含 945 张完整图片，下载量约 42.1 MiB；三种语言共用一个包。测试分别约束原基础资源低于 400 MiB、语言图片包低于 50 MiB。52 个剧情章节都有三语卡片；原本缺图的喜羊羊章节使用 `story-xyy/` 中的新素材。

## 新增图片

1. 查找原始档案中的对应语言、四态和尺寸，优先复用适配的原版素材。
2. 没有合适素材时，以原图生成完整图片并检查文字、透明边缘、状态色和切片边界。切片脚本只做离线几何处理。
3. 在对应目录清单登记 `canonicalPath`、`locale`、`file`、`width`、`height` 和来源，运行构建与校验。
4. 使用真实游戏组件检查中文、英文和韩文的显示，并提交素材、清单、工具和更新后的镜像资源。图片文字应在 PNG 内完成，不在运行时用色块和标题覆盖原图。
